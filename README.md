# MAX-чат — GREEN-API

Тестовое задание: веб-интерфейс для отправки и получения текстовых сообщений в MAX
через [GREEN-API](https://green-api.com/max). Прототип интерфейса — [web.max.ru](https://web.max.ru/).

## Запуск

Нужен Node.js 22+.

```bash
npm install
npm run dev                          # реальный GREEN-API
VITE_API_MOCKS=true npm run dev      # моки: все статусы и ошибки без инстанса
```

Вход — `idInstance` и `apiTokenInstance` из [личного кабинета](https://console.green-api.com).
Адрес API по умолчанию — `https://3100.api.green-api.com`; если у инстанса другой, его можно
указать в блоке «Дополнительно». Сценарии моков — [src/mocks/README.md](src/mocks/README.md).

### Настройка инстанса для получения

Приложение получает события через HTTP API (`receiveNotification` / `deleteNotification`), поэтому
в [личном кабинете](https://console.green-api.com) у инстанса должно быть:

- **Webhook URL — пустой.** Если он задан, события уходят на вебхук и очередь пуста — приложение
  покажет баннер и не будет запускать получение.
- **Включены уведомления:** о входящих сообщениях, об исходящих (с телефона и через API) и о статусах
  исходящих сообщений. Без них нет ответов собеседника, эха и отметок «доставлено / прочитано».

## Что готово

**Спринт 1 — вход и каркас**

- Вход с проверкой `getStateInstance`, понятные экраны для `notAuthorized`, `starting`
  (автоперепроверка 10 с × 30), `blocked`, `pendingPassword`, ошибки 401/429/5xx/офлайн/таймаут.
- «Запомнить меня»: `sessionStorage` или `localStorage`; при старте сохранённые данные проверяются
  заново (сплэш без мигания формы).
- Выход с полной очисткой, главный экран в раскладке web.max.ru (две колонки / одна на мобильном).
- Баннеры «Нет соединения», «Аккаунт ограничен», «Соединение восстановлено».
- Экран «Что-то пошло не так» вместо белого экрана. Светлая и тёмная тема.

**Спринт 2 — новый чат и отправка**

- «Новый чат» по номеру +7 / +375 в любом написании: проверка `checkAccount`, понятные ошибки
  (номер не в MAX, лимиты 466/469, инстанс не готов), повторный номер открывает существующий чат без запроса.
- Список чатов: свежие сверху, превью «Вы: …», время, статус последнего сообщения.
- Лента как в web.max.ru: группировка, разделители дней, текст строго как текст (HTML не исполняется).
- Поле ввода: Enter / Shift+Enter, рост до 6 строк, счётчик с 3800 символов, лимит 4000, черновики по чатам.
- Отправка `sendMessage` по `chatId`: сообщение сразу в ленте, очередь строго по одному в порядке ввода,
  статусы «отправляется / отправлено / не отправлено» и «Повторить» без дубля.
- Mobile: список или чат, «Назад» сохраняет прокрутку списка.

**Спринт 3 — получение, статусы, история**

- Цикл `receiveNotification` → обработка → `deleteNotification` в фоне: long-poll 20 с, бэкофф
  1–30 с при сбоях, баннер «Сервис недоступен» с обратным отсчётом после трёх сбоев подряд.
- Входящие текстовые — в нужный чат, новый собеседник — новый чат с именем; фото, файлы и прочее —
  плейсхолдер «не поддерживается»; группы игнорируются, битые события удаляются без остановки цикла.
- Без дублей: эхо своей отправки и повторная доставка склеиваются по `idMessage`; сообщения,
  отправленные с телефона, появляются справа.
- Статусы «доставлено / прочитано / не доставлено» (только вверх), «Повторить» для недоставленных.
- Непрочитанные: счётчик в списке, чат поднимается наверх, `(N) MAX-чат` во вкладке, пока она скрыта.
- Лента не прыгает, пока листаешь историю, — кнопка «↓» с числом новых.
- Баннеры: инстанс отключён (с автоперепроверкой), Webhook URL задан, входящие выключены, лимит тарифа.
- История чатов и сообщений переживает F5 (в том же хранилище, что и данные входа), очищается при выходе.

## Скрипты

| Команда            | Что делает                              |
| ------------------ | --------------------------------------- |
| `npm run dev`      | dev-сервер                              |
| `npm run build`    | проверка типов и production-сборка      |

## Стек и правила

React 19, TypeScript (strict), Vite, Tailwind CSS v4 поверх токенов дизайна, Radix UI, TanStack Query,
Zustand, React Router, react-hook-form + zod, Vitest, MSW. Архитектура — Feature-Sliced Design.

Правила разработки — [`docs/`](docs/README.md), дизайн — [`design/`](design/DESIGN.md).
