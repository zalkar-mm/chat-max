# Дизайн-спека — Спринт 5: обложка, кадры видео, скриншоты

База: `design/DESIGN.md`, токены `src/styles/tokens.css`. Все исходники лежат рядом: `cover-1280x640.svg`, `video-title-1920x1080.svg`, `video-end-1920x1080.svg` — редактируемые SVG на токенах DS, рендерить в PNG командой из §4.

## 1. Обложка проекта (1280×640) — задачи 1, 2, 5
Файл: `cover-1280x640.svg` → `docs/cover.png`. Используется: соцпревью GitHub (Settings → Social preview), `og:image` / `twitter:image` на демо, шапка README.
- Фон `--bg-surface #edeef2` (светлая тема — читается в превью Telegram/GitHub и в light, и в dark).
- Слева (x 96): логотип 64 radius 18 `--accent` + белый глиф пузыря (свой, не MAX) → название «MAX-чат» 56/600 `--text-primary` → подзаголовок 22/400 68 % в две строки «Отправка и получение сообщений в MAX / через GREEN-API» → ряд чипов 32h radius 16 `--bg-tertiary`: React · TypeScript · Vite · GREEN-API.
- Справа (x 620, 640×560, radius 20, обрезано снизу): макет главного экрана по DS — сайдбар 240 с тремя ячейками (selected «Анна», «Иван» с бейджем 2 и синим временем, номер с «Вы: »), шапка чата «Анна / +7 912 000-00-00», разделитель «Сегодня», три пузыря (in / out с двумя галочками / in), composer с кнопкой Send. Все данные — вымышленные; idInstance в шапке — `1101000001` (тестовый).
- Безопасная зона: Telegram и GitHub кадрируют края — ключевой контент внутри 64 px от границ (соблюдено: текст от x 96, окно до x 1260).
- Никаких реальных кредов, номеров, имён. Шрифт — системный (Roboto на Linux-рендере, SF на Mac) — при рендере в PNG ставить Roboto, чтобы совпало с видео.
- Вариант для dark не нужен: превью всегда показывается на карточке с собственным фоном.

Проверка: открыть PNG на 320 px ширины (как в Telegram на телефоне) — название читается, окно чата узнаётся как мессенджер.

## 2. Титр и финальный кадр видео (1920×1080) — задача 3
Файлы: `video-title-1920x1080.svg`, `video-end-1920x1080.svg` → PNG, в монтаж 2–3 с каждый с fade 300 ms.
- Фон `--bg-primary` dark `#17181c` — видео записываем в **светлой** теме (скриншоты и обложка светлые, видео-интерфейс тоже), а титры тёмные, чтобы визуально отделить «рамку» от самого приложения.
- Титр: логотип 160, «MAX-чат» 72/600, строка задания 30/400 80 %, стек 26/400 64 %, ссылка на демо 26 `--accent`. Всё по центру.
- Финал: логотип 96, «Спасибо за внимание» 44/600, два блока «Демо / GitHub» (подпись 64 %, ссылка `--accent`), внизу автор + Telegram 26/400 80 %.
- Плейсхолдеры `<демо>`, `<ник>`, `<репозиторий>` заменить перед рендером.
- Субтитры в видео: нижняя треть, 36/500 белый на `#000` 60 % radius 8 padding 8 16, max 2 строки, safe-area 96 px от низа. Без «выезжающих» анимаций.

## 4. Рендер в PNG
```bash
# из корня репозитория, нужен rsvg-convert (librsvg) или resvg
rsvg-convert -w 1280 -h 640  sprints/sprint-5/cover-1280x640.svg       > docs/cover.png
rsvg-convert -w 1920 -h 1080 sprints/sprint-5/video-title-1920x1080.svg > docs/video-title.png
rsvg-convert -w 1920 -h 1080 sprints/sprint-5/video-end-1920x1080.svg   > docs/video-end.png
```
Мета на демо (index.html): `<meta property="og:title" content="MAX-чат">`, `og:description` «Отправка и получение сообщений в MAX через GREEN-API», `og:image` → абсолютный URL `docs/cover.png` (или `/cover.png` в `public/`), `og:image:width/height` 1280/640, `twitter:card` `summary_large_image`. Favicon — из SPRINT-4 §7.
