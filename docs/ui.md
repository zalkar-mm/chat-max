# UI

Смежные темы: [code-style.md](code-style.md), [testing.md](testing.md).

Источник визуала — `design/DESIGN.md`, спеки спринтов, токены `src/styles/tokens.css`. Спека важнее этого файла:
при расхождении — правим правило.

## 1. Tailwind v4 поверх токенов дизайна

- `src/styles/tokens.css` — **единственный источник значений** (цвета, шрифты, радиусы, размеры, темы).
  Правится только вместе с дизайн-спекой.
- `src/app/styles/index.css` подключает Tailwind и токены и через `@theme inline` **ссылается** на переменные токенов:
  `--color-accent: var(--accent)`, `--color-bg-surface: var(--bg-surface)` → классы `bg-accent`, `bg-bg-surface`.
  Своих значений цветов в `@theme` нет; исключение — абсолютный `white` (иконки и текст на акценте в обеих темах).
- Типографика — утилиты `typo-*` (`@utility typo-body { font: var(--font-body) }`): `typo-hero`, `typo-title`,
  `typo-body`, `typo-detail`, `typo-description`, `typo-label`, `typo-action-large` и т.д. Размер шрифта
  классами `text-[..]` не задаём.
- Брейкпоинты — из спеки: `md` = 900px (две колонки), `xl` = 1280px (широкий сайдбар). Остальные стандартные отключены.
- Отступы и размеры — шкала Tailwind (шаг 4px покрывает спеку: `gap-1.5` = 6, `h-12` = 48, `px-4` = 16).
  Значение вне шкалы (393, 791) — токеном в `tokens.css` и `@theme`, а не `w-[393px]`.
- Тема — атрибут `data-theme` на `<html>`, переменные переключаются в `tokens.css`. Префикс `dark:` не нужен.
- `style={{}}` — только для рантайм-значений (высота авто-растущего поля).
- Кастомные классы под компонент в CSS — запрещены. Глобальный CSS — только reset, токены, `@utility`.
- **Mobile-first:** база без префикса, дальше `md:`, `xl:`. Минимальная ширина 320, горизонтального скролла нет:
  `min-w-0` во flex-детях, `max-w-full`.
- `prefers-reduced-motion` — анимации отключаются (`motion-safe:`/`motion-reduce:`).

## 2. `cn` и `cva`

- `cn` = `twMerge(clsx(...))` из `shared/lib/cn.ts`. Вызывается в теле, результат — в константу (`rootCn`).
  Пробрасываемый `className` — **последним**.
- `cva` — визуальные варианты примитивов (`variant`, `size`). Доменное соответствие
  (направление сообщения → стиль пузыря, тип баннера → цвета) — `Record` + `cn`.

## 3. Примитивы `shared/ui`

Дизайн полностью свой (MAX-like), поэтому **shadcn не используем**: переписывать его стили дороже, чем написать
примитив по спеке. Правила:

- Поведенческие примитивы (Dialog, Checkbox, Collapsible) — на `radix-ui`, стили — наши токены.
- Остальное — свои компоненты на `cva`: `Button` (primary / secondary / ghost / icon / plain), `Input`, `SecretField`,
  `Textarea`, `Spinner`, `InlineAlert`, `StatusScreen`, `Banner`, `Gate`, `Logo`, `Avatar`.
- Один компонент — один файл kebab-case, именованный экспорт. Компонент принимает нативные пропсы элемента
  (`ComponentProps<'button'>`) + свои варианты, `ref` пробрасывается (React 19 — обычным пропом).
- Нативные `<button>`, `<input>`, `<textarea>`, `<select>`, `<table>`, `<details>` вне `shared/ui` запрещены (ESLint).
  Кликабельная карточка (элемент списка чатов) — `Button variant="plain"`.
- Перед созданием компонента — проверить `shared/ui` и `entities/*/ui` (правило одного анализа).

## 4. Иконки

- Только `lucide-react`, импорт напрямую: `<Send className="size-5" aria-hidden />`.
- Размер — классы `size-*`. Цвет — наследуется (`text-*` на родителе). Декоративная иконка — `aria-hidden`.

## 5. Формы

- `react-hook-form` + `zod` + `@hookform/resolvers/zod`. Своих обёрток-«движков» над RHF не пишем.
- Схема и `useForm` — в `features/<slug>/model/use-<slug>-form.ts`. Хук возвращает модель формы (поля
  `register`, ошибки-строки, флаги, `onX`) — `ui/` получает её одним пропом `model` и не знает про запросы.
- Момент показа ошибок — `mode: 'onTouched'` + submit (как в спринтах). Исключение — номер телефона в «Новом чате»:
  `mode: 'onSubmit'` и проверка на blur только непустого поля (требование спринта 2).
- Ошибка поля: `aria-invalid` + `aria-describedby` на текст ошибки; текст заменяет подсказку.
- Ошибка сервера формы — `InlineAlert` над кнопкой; скрывается при изменении любого поля.

## 6. Уведомления и диалоги

- Ошибки показываются там, где возникли: под полем, над кнопкой, под пузырём, баннером. Тостов в спринтах 1–2 нет.
- `window.alert` / `confirm` / `prompt` — запрещены (ESLint). Диалог — `shared/ui/dialog` на Radix.

## 7. Состояния данных

Каждый блок с асинхронными данными явно показывает загрузку, ошибку, пусто, данные. Тексты — дословно из спринтов.
Ошибка никогда не выглядит как «пусто».

## 8. Тексты

- Интерфейс на русском, слоя i18n нет. Строка пишется прямо в JSX; подписи по статусу — `Record`.
- Время и даты — `Intl.DateTimeFormat('ru-RU')` через форматтеры: общие — `shared/lib/`, с доменными правилами
  («вчера», «Сегодня», разделители дней) — `entities/<x>/lib/`.
- Заголовок вкладки — элемент `<title>` в странице (React 19 поднимает его в `<head>`).

## 9. Доступность и касания

- Всё доступно с клавиатуры, видимый `:focus-visible` (outline 2px `--accent`, offset 2).
- У каждого контрола доступное имя (`<label>` или `aria-label`) — по нему же пишутся тесты.
- Хит-зона интерактивного элемента ≥ 40×40 (DESIGN §1).
- Живые регионы: ошибки — `role="alert"`, статусы — `role="status"`, лента — `role="log"`. Регион смонтирован
  заранее, меняется только содержимое — иначе скринридер может не объявить появившийся текст.
- Смена экрана без смены URL (форма → статус инстанса) переводит фокус на заголовок нового экрана.
- Модалка — focus-trap, `aria-modal`, Esc, возврат фокуса на инициатора (Radix Dialog).

## Что запрещено

- ❌ Цвета, шрифты, радиусы мимо токенов; `text-[13px]`, `bg-[#…]` — ревью.
- ❌ Кастомные классы под компонент в CSS — ревью.
- ❌ UI-библиотеки компонентов (MUI, Ant, shadcn-копипаст) — ревью.
- ❌ Нативные контролы вне `shared/ui`, `alert/confirm/prompt` — ESLint.
- ❌ Иконки не из `lucide-react`, свой `Icon`-маппер — ревью.
- ❌ Кликабельный `div`, контрол без доступного имени — `jsx-a11y`, тесты по ролям.
- ❌ Английский текст в интерфейсе — ревью.
