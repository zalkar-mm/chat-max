# UI

Смежные темы: [code-style.md](code-style.md), [testing.md](testing.md).

Прототип — web.max.ru. Точные размеры, цвета и состояния — из дизайн-спеки; при расхождении с этим
файлом спека важнее, а правило поправляем.

## 1. Tailwind v4

- **Нет `tailwind.config.*`.** Тема, шрифты, брейкпоинты — в `src/app/styles/index.css` через `@theme`, `@layer`, `@plugin`.
- Цвета — CSS-переменные темы (shadcn-токены: `bg-background`, `text-foreground`, `bg-primary`…).
  Палитра под MAX задаётся там же, а не в компонентах.
- Только шкала Tailwind: `gap-4`, `px-3`, `size-9`. Арбитрарные `bg-[#…]`, `gap-[14px]` — только если значения
  нет в шкале и его требует спека; тогда — токен в `@theme`, а не значение в классе.
- `style={{}}` — только для рантайм-значений (высота авто-растущего поля ввода).
- Кастомные классы под компонент в `index.css` (`.chat-bubble {}`) — запрещены.
- `!important` (`!p-4`) — нет.
- **Mobile-first:** база без префикса, дальше `md:`, `lg:`. На мобиле — список чатов и окно переписки
  отдельными экранами, на десктопе — две колонки.

## 2. `cn` и `cva`

```ts
// shared/lib/cn.ts
export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

- `cn` вызывается в теле компонента, результат — в константу (`rootCn`, `bubbleCn`).
  Пробрасываемый `className` — **последним**.
- `cva` — для визуальных вариантов примитивов (`variant`, `size`). Доменное соответствие
  (направление сообщения → стиль пузыря) — `Record<MessageDirection, string>` + `cn`.

## 3. shadcn/ui

- Только через CLI: `npx shadcn add <component>` → `src/shared/ui/`. Руками не копируем.
- Сгенерированный код не переписываем; точечная правка — комментарий сверху `// customized: …`.
- Берём по мере надобности: `button`, `input`, `textarea`, `label`, `form`, `scroll-area`, `avatar`,
  `dialog`, `tooltip`, `sonner`. Не ставим компоненты «на будущее».
- Нативный контрол там, где есть примитив (`<button>`, `<input>`), не используем — берём из `shared/ui`.

## 4. Иконки

- Только `lucide-react`, импорт напрямую: `<Send className="size-5" />`.
- Размер — классы `size-*`, не `width`/`height`. Цвет — наследуется (`text-*` на родителе).
- Своих `<Icon name="…">` нет.

## 5. Формы

- `react-hook-form` + `zod` + `@hookform/resolvers/zod` + shadcn `<Form>`/`<FormField>`/`<FormMessage>`.
  Своих обёрток над RHF не пишем.
- Схема — `features/<slug>/model/<slug>.schema.ts` (или `entities/<x>/model/`, если форма про одну сущность).
- Submit, `notify`, навигация — в `model/`, форма в `ui/` только вызывает `onSubmit`.
- Ошибки сервера → `form.setError(...)` или `notify.apiError(error)`.
- Поле сообщения: Enter — отправить, Shift+Enter — перенос; пустое/пробельное не отправляется;
  лимит 4000 символов ([data §1](data.md#1-контракт-green-api)).

## 6. Уведомления

- Движок — `sonner`, но импорт только через `@/shared/lib/notify`: `notify.success`, `notify.error`,
  `notify.apiError(error)`. `import { toast } from 'sonner'` вне `shared` запрещён.
- `<Toaster />` монтируется один раз в `app/App.tsx`.
- `window.alert` / `confirm` / `prompt` — запрещены.

## 7. Состояния данных

Каждый блок с асинхронными данными явно показывает: загрузку, ошибку, пусто, данные.

- Список чатов пуст — подсказка «создайте чат по номеру телефона».
- Чат без сообщений — пустое состояние, а не пустой экран.
- Исходящее сообщение: `pending` → `sent` / `failed` (с возможностью повторить).
- Ошибка никогда не выглядит как «пусто».
- Новое сообщение — автопрокрутка вниз, если пользователь уже внизу ленты.

## 8. Тексты

- Интерфейс на русском, слоя i18n нет. Строка пишется прямо в JSX.
- Строка, общая для нескольких компонентов, — экспорт из модуля рядом; подписи по статусу — `Record`.
- Время — `Intl.DateTimeFormat('ru-RU')` через форматтер в `shared/lib/`.
- Ошибки — человеческим языком, без кодов и стектрейсов («Неверный idInstance или apiTokenInstance»).

## 9. Доступность и касания

- Всё доступно с клавиатуры, видимый `:focus-visible`.
- У каждого контрола доступное имя (`<label>` или `aria-label`) — по нему же пишутся тесты.
- Кликабельный `div` запрещён — только `<button>`/`<a>` с правильной семантикой.
- Лента сообщений — `role="log"` + `aria-live="polite"`.
- Тач-цель не меньше 44 × 44 px; нет горизонтального скролла на ширине 360 px.

## 10. Композиция

- Пропсы минимальные и конкретные (ISP). Растёт число `variant`/`renderX` — переходим на композицию через `children`.
- Перед созданием компонента — проверить `shared/ui` и `entities/*/ui` (правило одного анализа).

- ❌ Ручной копипаст shadcn, свои обёртки над RHF, UI-библиотеки кроме shadcn (MUI, Ant) — ревью.
- ❌ `import { toast } from 'sonner'` вне `shared/lib/notify`, `window.alert/confirm/prompt` — ESLint [инфра].
- ❌ Свой `Icon`-маппер, иконки не из `lucide-react` — ревью.
- ❌ Кликабельный `div`, контрол без доступного имени — тесты по ролям, ревью.
- ❌ Английский текст в интерфейсе — ревью.
